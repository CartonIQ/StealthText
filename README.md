## ✨ Features

- 🔐 **Encode Text:** Hide AES-256 encrypted messages inside photos.
- 📂 **Hide Files:** Embed PDFs and TXT files into images.
- 🎙️ **Voice Studio:** Record and hide audio messages.
- 🕵️ **Decoy Password:** Set a second password that reveals a completely different fake message.
- 📸 **Stealth Watermark:** Embed invisible copyright tags.
- ✂️ **Shamir Split:** Split a secret into 3-5 images. You need multiple images to rebuild it.
- 👻 **Invisible Text:** Hide messages inside normal text using zero-width characters.
- 🔢 **Calculator Disguise:** The app looks like a working calculator until you enter your PIN.
- 🛡️ **Security:** Fake crash screen, duress PIN, shake-to-lock, and biometric vault.
